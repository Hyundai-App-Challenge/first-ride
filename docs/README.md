## 참고 자료 (`reference/`)

선정 단계에서 만든 자료 가운데 기획서 작성과 구현에 계속 쓰는 것만 옮겨 두었다. 목록과 용도는 [reference/README.md](reference/README.md) 참조. 나머지 선정 과정 기록은 프로젝트 루트의 `archive/`에 있다.

## 먼저 할 일

1. **에뮬레이터 실측** — 기술 설계 13절의 T1~T15. T1(에뮬레이터가 도는가)이 가장 먼저다. 하드웨어는 충족했고(RTX 3060 12GB) 실제 실행은 아직 확인하지 않았다. 결과에 따라 코스 구성과 수치가 바뀐다.
2. **팀 결정** — PRD 10절의 D1~D7. D1(앱 이름), D2(기준 차종), D3(김서림 제거 목표 조합)은 11-14까지.

## 문서 고치는 규칙

- 용어는 용어집을 따른다. 새 용어가 필요하면 용어집에 먼저 넣는다.
- 여러 기능에 걸친 규칙은 정책서에 적는다. 정책서와 기능 명세서가 어긋나면 정책서가 우선이다.
- 기능을 더하거나 뺄 때는 PRD 5절(범위)을 먼저 고친다. "하지 않는 것"에 있는 항목을 넣으려면 팀 합의가 필요하다.
- 실측으로 확인한 값은 `[실측]` 표시를 지우고 결과를 적는다.
- `[가정]` 은 근거 없이 정한 값, `[미정]` 은 팀 결정이 필요한 항목이다.
